# AI-Powered Customer Emotion Intelligence System

## 📌 Project Overview
This project performs sentiment analysis, emotion detection, and churn prediction on customer feedback using Python.

## 🚀 Features
- Sentiment Analysis (Positive / Negative / Neutral)
- Emotion Detection (Joy, Anger, Sadness, Neutral)
- Customer Scoring System
- Churn Risk Prediction
- Data Visualization using Matplotlib

## 🛠 Technologies Used
- Python
- Pandas
- Matplotlib
- Collections

## 📊 Output
Generates:
- Sentiment distribution
- Emotion distribution
- Customer risk analysis
- CSV output file
